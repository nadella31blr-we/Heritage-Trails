# Heritage-Trails

Mobile-friendly heritage walk website for Bhubaneswar (Project 10, Group 1 / Team 3).
Product goal: mapped trails, site stories, visitor tips and feedback for at least two self-guided walks.

## Run it
Open `index.html` in a browser. No build step and no server needed.

## Files
- `data/sites.js`: site data taken from the team research sheet. Add `story`, `image` and `imageAlt` per site as content is ready.
- `site.html`: the reusable site page template (APDG3-28). It shows one site, chosen by `?site=<id>`.
- `assets/`: styles and the script that fills the pages.
